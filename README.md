# Drones Helping People

Aerial mapping for field research, teaching and community partnerships, coordinated by Kytt MacManus with collaborators at Columbia University and partner organizations.

The [website](https://kyttmacmanus.github.io/drones-helping-people-preview/) documents four program areas: Teaching & Workshops, Communities, NYC Parks and Research. V6.1 introduces an illustrated overview, selected projects, an eight-node timeline summary and an expandable full timeline of thirteen milestones. The field atlas contains 109 reviewed photographs and spatial-product displays. The Highbridge project includes a survey orthomosaic and textured water-tower reconstruction; SAMARA describes continuing aerial-logistics research for electrification and infrastructure operations.

Descriptions distinguish field activities, processed products and research outcomes. Display imagery does not establish independent survey accuracy. The DARPA banner supplies event context and does not identify SAMARA's aircraft.

Append `?edition=efpl` for the Environmental Flow Physics Laboratory perspective. Credits remain specific to each project and collaboration. The Mtukuzi educational contribution links to TOPSTSCHOOL.

GitHub Pages publishes this website from the repository root. V6.1 begins a clean public Git baseline; development history and complete research provenance are retained privately. Deployment checks validate the public data fields, image permissions, embedded metadata and wording before publishing. Older copies, forks and cached commit views may persist outside this branch.
