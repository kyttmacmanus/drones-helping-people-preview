# Drones Helping People

A Columbia University portfolio by Kytt MacManus and collaborators: drone-based mapping, field education and community-engaged research through EFPL and CIESIN.

The [HTML site](https://kyttmacmanus.github.io/drones-helping-people-preview/) connects four program areas—Teaching & Workshops, Communities, NYC Parks and Research—with independent project case studies, field photographs, spatial products and scientific methods. A visual Program timeline presents twelve selected milestones. The atlas includes a sampled Lamont photogrammetric point viewer. The Mtukuzi educational contribution links to its canonical home at TOPSTSCHOOL.

Descriptions distinguish observations, derived products, interpretations, intended applications and forthcoming work. Resolution is distinct from independent accuracy, and terrain geometry is an input to research rather than a validated wind model.

The default personal perspective uses Kytt's byline; append `?edition=efpl` for the Environmental Flow Physics Laboratory perspective. Project-specific institutional and collaborator credits persist across both.

The project has its own abstract network logo and program-area palette, with Columbia affiliation visible as secondary attribution. Communities presents distinct Staten Island and Mtukuzi collaborations. Teaching includes Black Rock Forest balloon mapping as a historical precursor, William Paterson campus tree mapping, Hemlock Hill field methods and UNZA/HOT exchange. A sourced UNZA textured mesh provides the featured 3D example. Structured image/product metadata and basemap-free product displays remain central; balloon imagery, photogrammetry, LiDAR and qualitative thermal displays remain distinct.

GitHub Pages serves this curated website-only snapshot from the main branch root. Development records and source archives are maintained separately.

The publication-hardened release serves 109 reviewed atlas records with public interpretation metadata and deliberate external references. Complete research provenance is maintained separately. Repository deployment checks validate the publication schema, rights categories, workspace-link exclusions and embedded image metadata before producing the Pages artifact.
